1. Contexte & Objectifs

Ce projet formalise la conception, le déploiement et le durcissement d'une infrastructure réseau et applicative pour la Maison des Ligues de Lorraine (M2L). L'objectif est de fournir un environnement de production hautement sécurisé pour la gestion des clubs sportifs, en isolant les serveurs exposés à Internet des bases de données critiques.

Le choix s'est porté sur une sécurisation par zones étanches (Zone-Based Security) adossée aux ports physiques du Zyxel USG40 - tout mécanisme VLAN écarté pour éliminer les risques de VLAN Hopping.

6. Architecture Applicative 3-Tiers

  • Tier Présentation : Port public 8080 → PAT vers port 80 de SRV-WEB.
  • Tier Application (SRV-WEB) : Apache + PHP. Liaison via PDO - injections SQL impossibles. Mots de passe en Bcrypt.
  • Tier Données (DEB-BASKET) : MariaDB 10.11 en LAN2 - inaccessible depuis Internet.

7. Plateforme SFTP & Fail2Ban

  • SFTP : Tunnel SSH unique. NAT-Loopback port externe 2222 → interne 22.
  • Cloisonnement : dev-web et resp-basket confinés à leur home (chmod 700).
  • Fail2Ban : Bannissement iptables dès le 4ᵉ échec (maxretry=3), bantime 30s pour le jury.

8. Runbook d'Incidents

Incident Majeur : Erreur SQL 1130

Symptôme

"Host is not allowed to connect to this MariaDB server" lors des requêtes PDO.

Diagnostic

SNAT du Zyxel : MariaDB reçoit les requêtes avec l'IP passerelle 10.0.20.254 au lieu de l'IP réelle de SRV-WEB.

Résolution

GRANT ALL PRIVILEGES ON m2l_data.* TO 'm2l_admin'@'10.0.20.254'

Incident Mineur : "No Route to Host" sur apt update

Résolution

Route statique injectée dans l'USG40 vers la passerelle école 192.168.193.1.
