1. Contexte & Objectifs

Ce projet implémente une solution de supervision d'entreprise et un centre opérationnel de sécurité (SOC) pour la M2L, unifiés sur une console de contrôle unique. L'objectif est de détecter instantanément deux menaces majeures : les attaques périmétriques par force brute et les tentatives d'altération interne de fichiers de configuration critiques.

L'ensemble des flux de supervision transite de manière étanche à travers les zones physiques du pare-feu Zyxel USG40, en couche de surveillance complémentaire au Projet 1.

4. Contrôle d'Intégrité de Fichiers (FIM)

Le FIM surveille en continu /etc/ssh/sshd_config sur SRV-FTP. Toute modification d'un seul octet est détectée en moins de 10 secondes.

NomIntégrité du fichier sshd_config

Compare la dernière empreinte avec la précédente via l'opérateur last(…,#2). Toute modification bascule l'hôte en état PROBLEM / High / Rouge clignotant.

6. Runbook d'Incidents

Incident Critique : Pastilles Rouges - Rejet ACL Agents

Symptôme

Dès l'activation des règles inter-zone, les trois pastilles ZBX passent en Non Available (Rouge) - message : "Received empty response from Zabbix agent… access permissions".

Diagnostic

Le SNAT du Zyxel masque l'IP source : les agents reçoivent les requêtes de 10.0.40.254 (passerelle DMZ) et non de 10.0.20.10 (SRV-MONITOR), IP non listée dans leur ACL locale.

Résolution

Modification de /etc/zabbix/zabbix_agentd.conf :

SRV-FTP/WEB : Server=10.0.20.10,10.0.40.254
SRV-MONITOR : Server=127.0.0.1,10.0.20.254

7. Script de Validation (Oral)

  • Démonstration FIM : Console Proxmox SRV-FTP → echo "# Test jury" >> /etc/ssh/sshd_config → en moins de 10s, alerte rouge clignotante dans le widget "Alertes de Sécurité Actives".
  • Démonstration SOC / Fail2Ban : 4 échecs WinSCP sur le port 2222 → widget "Flux des Intrusions" affiche NOTICE [sshd] Ban 10.0.40.254 - preuve de la corrélation NAT par le pare-feu.
